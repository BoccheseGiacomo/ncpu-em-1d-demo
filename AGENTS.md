# Agent guide: ncpu-em-1d-demo

A static GitHub Pages site that runs a frozen NCPU-EM-1D model (a 1D neural
cellular automaton) in plain JavaScript. There is no build step and no
dependencies. The README describes the features and the current model.

## Layout

| File | Role |
|---|---|
| `index.html`, `style.css`, `app.js` | Page and UI. `app.js` loads `nca.js`, `model.json` and `results.json` with its own `?v=` tag |
| `nca.js` | Inference engine, a pure ES module with no DOM. `step()` mirrors `NeuralCellularAutomaton._step` in `ncpu_computer_1d/model.py`, operation by operation |
| `model.json` | Exported weights and config. Generated: never edit it by hand |
| `results.json` | Accuracy table, tied to the model by `model_md5`. Generated by `tools/measure_accuracy.py` |
| `tools/export_model.py` | Checkpoint → `model.json` + `tests/fixtures.json`. Needs PyTorch and the `ncpu-em-1d` project via `--project` |
| `tools/measure_accuracy.py` | Checkpoint → `results.json` (training schedule, last step, ID plus OOD +k, sync and/or async) |
| `tests/verify.mjs` | Checks `nca.js` against PyTorch: exact replays with recorded firing masks, plus a sampled-accuracy z-test. `--quick` runs the replays only |

## Rules

- **Run `node tests/verify.mjs` after any change to `nca.js` or `model.json`.** It must print "all checks passed".
- **Bump `?v=N` in `index.html` (it appears twice) on every deploy.** GitHub Pages caches each file for 10 minutes,
  and the tag keeps browsers from mixing old and new files.
- **Keep the UI driven by `model.json`:** tasks, channels, program placement and mode, firing rate and timing. Don't
  hard-code a particular model. Task formulas live in `TASK_INFO` in `app.js`, and the transforms in `TASKS` in
  `nca.js`. Both cover all 12 tasks of `ncpu_computer_1d`.
- **Firing:** the page defaults to synchronous firing. `async=1` in the URL hash runs with the model's trained random
  firing.
- **Keep the page usable at phone width (375 px) with no sideways page scroll.** Wide content scrolls inside its own
  box.
- **Preview locally over HTTP:** `python -m http.server 8137`, then open <http://localhost:8137>.
- **Deploy:** push to `main`. Pages serves the repository root, and `.nojekyll` makes it serve files as they are.
