How it works

The tape is a one-dimensional row of cells. Each cell holds a vector of values, organised into channels: program channels that hold the learned task program and stay fixed during a run, one input/output (I/O) channel, and hidden channels the model uses as working memory.

The binary input is written into the I/O channel (0 → −1, 1 → +1, blank → 0), and the chosen task's program fills the program channels. At every time step, each cell looks at its own vector and those of its nearest neighbours, and one small neural network computes an update. The network is the same for every cell, every step and every task; only the program differs between tasks. As in training, updates are stochastic: at each step a random subset of cells fires, and the seed makes this reproducible.

After enough steps the answer appears in the I/O channel. Training asked for it at the end of rollouts as long as the automatic number of time steps. Longer runs, longer inputs and larger tapes show how far the learned rule generalises.

Inspired by NCPU and Emergent Models: Intelligence from Tiny Substrates. The frozen weights run locally in your browser; nothing is sent anywhere.
